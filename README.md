# Spoof Detection

> **Deprecated, and this repository is archived.** No new versions will be published.
>
> It fused `Spoof-Device-Detection-Ver-ID-3-Apple`'s device check with the FASnet model, and
> nothing depends on it: not the on-device packages, not the registry app, and not the legacy
> `Ver-ID` pod. The FASnet half is archived with it.
>
> Use [`Spoof-Device-Detection-Ver-ID-3-Apple`](https://github.com/AppliedRecognition/Spoof-Device-Detection-Ver-ID-3-Apple)
> instead.
>
> Archiving makes the repository read-only. It stays clonable and its tags stay resolvable,
> so an existing `Package.resolved` that pins a version here keeps working.

Spoof detection using fusion score of [Spoof device detection](https://github.com/AppliedRecognition/Spoof-Device-Detection-Ver-ID-3-Apple) and [FASnet spoof detection](https://github.com/AppliedRecognition/Spoof-Detection-Fasnet-Apple).
